# 🐶 Dog API Practice

A simple project I created to practice working with a Dog API and learn how to retrieve and display data from an external API using JavaScript.

## About the Project

This project was built for practice while learning how APIs work. I used a Dog API to make requests and work with the data returned by the API.

## What I Practiced

* Making API requests
* Working with API responses
* Using JavaScript with external data
* Accessing data returned from an API
* Displaying dog information/images
* Debugging API requests
* Understanding asynchronous JavaScript

## Technologies Used

* HTML
* CSS
* JavaScript
* Dog API

## What I Learned

This project helped me better understand how JavaScript communicates with an API, how data is returned from an API, and how that data can be used in a web application.

## Purpose

This is a learning project created as part of my journey practicing JavaScript and web development.
